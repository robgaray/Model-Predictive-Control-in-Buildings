# Required R libraries for the standalone market script
# -------------------------------------------------------------
# Only what the code actually calls:
#   GA          - ga(), the genetic algorithm of the optimizer
#   doParallel  - registerDoParallel(), when the optimizer runs parallel.
#                 Loading it also attaches parallel and foreach, whose
#                 functions the optimizer calls unqualified:
#                   - makeCluster(), clusterExport(), clusterEvalQ(),
#                     stopCluster() (parallel)
#                   - registerDoSEQ() (foreach)
#   doRNG       - not called directly. ga() evaluates its
#                 population through doRNG's %dorng% when doRNG
#                 is installed, and optimize_modes() makes it do
#                 so in series and in parallel alike, so that
#                 both follow the same random sequence. It must
#                 therefore be installed everywhere.
#   Rcpp        - sourceCpp(), to build the simulation core
#   jsonlite    - read_json()/write_json(), in call_script_console.R
# -------------------------------------------------------------

doParallel
