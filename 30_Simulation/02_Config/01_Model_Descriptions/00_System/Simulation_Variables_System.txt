# Declarative registry of the variables of the system: the balances
# that Main_df holds for the whole system, behind its single
# connection point with the grid. Read by variable_registry_columns()
# to build the columns of System_variables_df, which
# assemble_main_df.R joins into Main_df. The variables of each asset
# are declared in the registry of its type of model (for a building,
# 01_Building/Simulation_Variables_Building.txt) and live in the
# table of the asset, not in Main_df.
#
# The variables:
#   Elec_total          : net electricity of the system in each
#                         itinerary, the sum of the Elec_total of its
#                         assets. It is the one column that both
#                         Main_df and the table of an asset hold.
#   Elec_total_no_flex  : the executed net electricity of the system
#                         without an executed flexibility event.
#   Elec_flex_down_plan,
#   Elec_flex_up_plan   : the flexibility committed by the system on
#                         each leg, the net of what its assets
#                         contribute.
#   Elec_*_h            : the cash flows of the system on each row.
#
# Columns:
#   variable      : base variable name.
#   type          : semantic category (energy | economic).
#                   Documentation only, not used to drive any logic.
#   initial_value : value of the variable on every row of the
#                   assembled Main_df.
#   scenario      : yes -> the variable is expanded into 4 columns,
#                   <variable>_exec, <variable>_plan,
#                   <variable>_plan_flex_down and <variable>_plan_flex_up.
#                   no  -> the variable is kept as a single column,
#                   <variable>, with no suffix.
# -------------------------------------------------------------
variable	type	initial_value	scenario
Elec_total	energy	0	yes
Elec_total_no_flex	energy	0	no
Elec_flex_down_plan	energy	0	no
Elec_flex_up_plan	energy	0	no
Elec_market_net_cost_h	economic	0	no

Elec_net_cost_h	economic	0	no

Elec_flex_execution_revenue_h	economic	0	no
Elec_flex_deviations_net_cost_h	economic	0	no
Elec_cost_distr_h	economic	0	no
